# Code of conduct

This project welcomes people of all backgrounds and experience levels. Discuss
technical choices with evidence, assume good intent and make room for questions.
Critique work without attacking the person doing it.

Harassment, threats, discriminatory language, sexual attention, deliberate
disruption and publishing someone else's private information are not acceptable
in project issues, pull requests, discussions or other project spaces.

Maintainers may edit or remove inappropriate contributions, ask someone to stop,
or restrict participation. Decisions should be proportionate and protect
participants' privacy. Good-faith disagreement is welcome.

For a conduct concern, request a private channel from a maintainer without
posting personal details publicly. GitHub's abuse-reporting mechanisms are also
available. For a software vulnerability, use [SECURITY.md](SECURITY.md).
